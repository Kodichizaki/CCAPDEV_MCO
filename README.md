Prerequisites: 

- [Node.js](https://nodejs.org/) (v18 or higher)
- [MongoDB Community Server](https://www.mongodb.com/try/download/community) (v6 or higher)
- [MongoDB Compass](https://www.mongodb.com/products/compass) (optional, for viewing the database)


Run this in the project folder to install all required packages:
npm install

This will install: express, mongoose, cors, bcrypt, multer, and hbs.

Make sure your MongoDB server is running before starting the website.
On Windows, open Services and make sure **MongoDB Server** is running,

Seed the Database:
node seed.js

Start the Server:
node server.js
